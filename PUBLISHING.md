## Full description

DragonAltar turns a server's Ancient Dragon event into a persistent RPG system centered on exactly three Dragon Souls: Akuma, Rev, and Lamari. Staff configure an existing altar and End fountain. DragonAltar starts the vanilla respawn sequence, tracks the canonical dragon, awakens the altar, and creates three persistent soul records.

Players claim souls through rituals and retain them through a controlled inheritance and reincarnation system. Each soul has its own passive identity, movement and combat abilities, a full-energy ultimate, and pair or three-player resonances. Persistent state, exact-item ritual refunds, recovery logic, accessibility settings, configuration migration, and bounded targeting support long-running SMP use.

DragonAltar uses displays and particles for staged effects. It does not create real explosions, permanent terrain tasks, or destructive ability terrain. Temporary Frost Run ice is tracked and reverted safely.

## Installation

1. Stop Paper 1.21.4.
2. Place `DragonAltar-1.4.16.jar` in `plugins`.
3. Start with Java 21.
4. Complete `/dragon setup begin`, `/dragon setup save`, and `/dragon setup validate`.
5. Review the generated configuration and complete the live release checklist.
